# Guia do Higienizador

Crie um site mobile-first chamado “Guia do Higienizador”, desenvolvido como uma ferramenta de consulta rápida para profissionais que estão começando ou se aperfeiçoando no ramo de higienização de estofados.

O site deve funcionar como um manual digital prático, permitindo que o profissional encontre rapidamente informações sobre tecidos, estofados, produtos, manchas, procedimentos, equipamentos e cuidados.

1. OBJETIVO DO SITE

O objetivo é ajudar o higienizador profissional a tomar decisões melhores durante o trabalho.

O usuário deve conseguir consultar, de forma simples:

Qual é o tipo de tecido?

Qual a composição provável?

Quais são suas características?

Quais produtos podem ser utilizados?

Quais produtos devem ser evitados?

Como testar o tecido?

Como tratar determinada mancha?

Como fazer a pré-inspeção?

Qual processo de limpeza utilizar?

Quais cuidados tomar?

Como evitar danos ao estofado?

O site deve ter uma linguagem profissional, mas fácil de entender, sendo útil tanto para iniciantes quanto para profissionais experientes.

## Publicar na HostGator (sem Node no servidor)

```sh
npm run publicar
```

Gera **`PUBLICAR-HOSTGATOR.zip`** (site + API PHP + `config.php` de teste).

1. Extrair em `public_html/guiadohigienizador` (mostrar arquivos ocultos)
2. phpMyAdmin → banco `will3269_GUIA` → Importar `api/schema.sql`
3. Abrir `/api/health` → `"db": true`

Sem Node, Laravel ou Supabase no servidor. OpenAI é opcional em `api/config.php`.  
Detalhes: [docs/deploy-hostgator.md](docs/deploy-hostgator.md). Zip sem senha: `npm run build:cpanel` → `cpanel.zip`.
