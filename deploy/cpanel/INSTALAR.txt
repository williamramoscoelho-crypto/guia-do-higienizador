  GUIA DO HIGIENIZADOR — INSTALAÇÃO EM 3 PASSOS (HostGator)
═══════════════════════════════════════════════════════════

Site: https://guiadohigienizador.autolimpezapro.com.br
Pasta: public_html/guiadohigienizador
(NÃO use a raiz da Auto Limpeza Pro.)

───────────────────────────────────────────────────────────
PASSO 1 — Extrair este zip
───────────────────────────────────────────────────────────
1. cPanel → Gerenciador de Arquivos → mostrar arquivos ocultos
2. Abra public_html/guiadohigienizador
3. Envie e EXTRAIA este zip DENTRO dessa pasta
4. Confira no mesmo nível:
     index.html
     .htaccess
     assets/
     api/
     INSTALAR.txt

───────────────────────────────────────────────────────────
PASSO 2 — Banco MySQL (1 clique)
───────────────────────────────────────────────────────────
No cPanel, crie o banco + usuário e associe com todos os privilégios
(ex.: will3269_GUIA). Não precisa importar schema no phpMyAdmin.

1. Abra no navegador:
     https://guiadohigienizador.autolimpezapro.com.br/api/instalar.php
2. Preencha host/banco/usuário/senha MySQL + senha do instalador
   (ou, se já existe api/config.php, digite só a install_key)
3. Clique em **Instalar em 1 clique** (primeira vez)
   ou **Atualizar banco** (quando republicar o site)
4. Teste /api/health → "db": true

Alternativa antiga: phpMyAdmin → Importar api/schema.sql

Se o zip NÃO trouxe config.php:
  o próprio instalar.php pode criar; ou copie
  api/config.example.php → api/config.php

───────────────────────────────────────────────────────────
PASSO 3 — Testar
───────────────────────────────────────────────────────────
  /api/health     → deve mostrar "db": true
  /               → home do Guia
  /auth           → cadastro / login
  /comunidade     → posts
  /ia             → só com openai_api_key no config.php

SSL (Let’s Encrypt) no subdomínio guiadohigienizador.

Troque a senha do MySQL depois (teste).
IA: gemini_api_key (Google AI Studio) e/ou openai_api_key em api/config.php.
Opcional: apague api/instalar.php depois de usar.
Sem Node, sem Laravel, sem Supabase no servidor.
